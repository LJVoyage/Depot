# Unity 路径代码生成器 · 操作文档

## 打开工具
在 Unity 顶部菜单栏点击：  
**VoyageForge → Depot → Generate Asset Paths**

---

## 使用步骤

### 1. 选择根目录
- 在 **“根目录”** 字段中，点击或从 Project 窗口**拖拽一个文件夹**到该框内。
- 工具会自动扫描该文件夹下的**所有子文件夹**。
- 如果误选了文件，会自动提取其所在目录。

### 2. 选择输出目录
- 在 **“输出目录”** 字段中，同样点击或拖拽选择**生成的 `.cs` 文件**要存放的位置。
- 若文件夹不存在，工具会自动创建。

### 3. 设置类名（可选）
- 在 **“类名”** 输入框中，自定义生成的静态类名称，默认为 `AssetPaths`。

### 4. 生成代码
- 点击 **“生成代码”** 按钮。
- 工具会在输出目录生成两个文件：
    - `类名.Base.template.cs`（**仅首次生成**，后续不会覆盖）
    - `类名.g.cs`（**每次覆盖**，包含所有嵌套路径类）

---

## 配置 Base 路径（关键步骤）

1. 打开输出目录，找到 `类名.Base.template.cs`（例如 `AssetPaths.Base.template.cs`）。
2. 用代码编辑器打开，修改 `Base` 常量的值为**您实际的资源根路径**（例如 `"Assets/GameRes/"`）。
3. **将文件重命名**（推荐）：去掉 `.template`，改为 `类名.Base.cs`（例如 `AssetPaths.Base.cs`）。  
   （不重命名也可以，只要确保文件以 `.cs` 结尾且参与编译即可。）

> 模板中的 `Base` 默认值已自动填充为您选择的根目录，大多数情况只需重命名，无需修改内容。

---

## 使用生成的路径常量

在您的业务代码中，即可通过智能提示访问路径：

```csharp
string path = AssetPaths.Textures.Intervention.Base;
```

所有文件夹都会生成对应的嵌套类，鼠标悬停时，如果文件夹有别名，会显示在 XML 注释中。

---

## ⚠️ 注意事项

- **不要修改 `类名.g.cs`**，它每次生成都会被覆盖。
- **`类名.Base.template.cs` 只生成一次**，可放心修改和重命名。
- 如果根目录下没有子文件夹，工具会提示并停止生成。
- 文件夹名称中的非法字符（空格、点、横线等）会自动替换为下划线 `_`。

## ❓ 常见问题

**Q：生成后报错找不到 `ForgeMetaDatabase`？**  
A：若不需要别名功能，可忽略该错误；若需要，请确保这两个类型在项目中存在且引用了正确的命名空间。

**Q：如何修改生成的类名？**  
A：在工具窗口的“类名”输入框中修改，重新生成即可。

**Q：Base 路径写错了怎么改？**  
A：直接修改 `类名.Base.cs` 文件中的 `Base` 常量值。
